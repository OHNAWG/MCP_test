# 🎹 키보드 입력 테스트 프로그램

키보드 입력을 시각적으로 테스트하고 모니터링할 수 있는 웹 기반 애플리케이션입니다.

## 기능

✨ **주요 기능**
- 🎯 실시간 키보드 입력 감지
- 🖱️ 마우스 클릭으로 버튼 입력 가능
- 📊 입력 통계 및 추적
- 📱 반응형 디자인 (모바일 지원)
- 🎨 심플한 흰색 기반 UI

## 사용 방법

1. **파일 열기**
   - `keyboard_test.html` 파일을 웹 브라우저에서 엽니다
   - Chrome, Firefox, Safari, Edge 등 모든 최신 브라우저 지원

2. **입력 테스트**
   - 실제 키보드를 눌러서 입력
   - 또는 화면의 버튼을 클릭해서 테스트
   - 입력된 키가 중앙 디스플레이에 표시됨

3. **통계 확인**
   - 마지막 입력 키 확인
   - 총 입력 횟수 추적
   - 초기화 버튼으로 통계 리셋

## 기술 스택

- **HTML5** - 구조
- **CSS3** - 스타일링 및 애니메이션
- **Vanilla JavaScript** - 인터랙티브 기능
